# SurfaceFlinger 是什么?
# ----------------------
# SurfaceFlinger 是 Android 系统的核心图形服务,负责:
# 1. 管理所有应用的显示图层(Layer)
# 2. 将多个图层合成为最终显示画面
# 3. 与硬件显示控制器(HWC)通信
# 4. 同步 VSYNC 信号确保流畅显示
# 
# 这个文件包含了系统显示的所有底层信息,帮助开发者诊断显示问题
# ============================================================

# 各项参数说明:
# - PRESENT_TIME_OFFSET=0       : 显示时间偏移(0表示无偏移)
